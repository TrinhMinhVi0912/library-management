## Làm
1. `auth.middleware.js`: đọc `Authorization: Bearer`, verify access JWT, nạp user (kiểm tra `status:'active'`), gắn `req.user`; lỗi 401.
2. `requireRole(...roles)`: 403 nếu sai vai trò. `validate(schema, source)`: joi, trả 422 với `errors`.
3. `rateLimit.middleware.js`: limiter chung và limiter nghiêm cho `/auth/*` và đăng bài diễn đàn.

## Ghi chú cho task sau
- Middleware xuất khẩu từ `app/middlewares` bao gồm:
  - `auth`: xác thực JWT access token, nạp `req.user`, chặn 401 nếu thiếu/sai/hết hạn hoặc tài khoản bị khóa (`status !== 'active'`).
  - `auth.optionalAuth`: không bắt buộc token, có token hợp lệ thì nạp `req.user`, ngược lại để `req.user = null`.
  - `requireRole(...roles)`: nhận role rời rạc hoặc mảng, chặn 403 nếu `req.user.role` không thuộc danh sách, chặn 401 nếu chưa đăng nhập.
  - `validate(schema, source = 'body')`: validate Joi schema (hoặc object `{ body, query, params }`), chuẩn hóa format lỗi trả về 422 `{ success: false, message, errors: [{ field, message }] }`.
  - `generalLimiter`, `authLimiter`, `forumPostLimiter`: rate limiter cho API chung, route auth, và đăng bài diễn đàn.
- `ApiError.unprocessableEntity(message, errors)`: helper tiện dụng cho lỗi 422.
