# BE-07 – Middleware nền: auth, requireRole, validate, rateLimit
- Track: Backend · Giai đoạn: B2 Auth
- Phụ thuộc: BE-06
- Phạm vi: **một cuộc trò chuyện**; chỉ làm đúng việc dưới đây.

## Làm
1. `auth.middleware.js`: đọc `Authorization: Bearer`, verify access JWT, nạp user (kiểm tra `status:'active'`), gắn `req.user`; lỗi 401.
2. `requireRole(...roles)`: 403 nếu sai vai trò. `validate(schema, source)`: joi, trả 422 với `errors`.
3. `rateLimit.middleware.js`: limiter chung và limiter nghiêm cho `/auth/*` và đăng bài diễn đàn.

## File tạo/sửa
- `app/middlewares/{auth,requireRole,validate,rateLimit}.middleware.js`

## Xong khi
- [ ] Route thử có `auth` không token → 401; sai role → 403; body sai → 422
- [ ] Lint sạch; `/done` đã cập nhật INDEX + SESSION
