# BE-08 – Auth: đăng ký, đăng nhập, refresh, đăng xuất
- Track: Backend · Giai đoạn: B2 Auth
- Phụ thuộc: BE-07
- Phạm vi: **một cuộc trò chuyện**; chỉ làm đúng việc dưới đây.

## Đọc (chỉ những mục này)
- digest §D1, D2, D9
- docs/04 §3.1, §6; docs/01 §7.1

## Làm
1. `auth.service.js`: `register` (role reader, mã `DG…`, bcrypt cost 10–12, kiểm tra độ mạnh), `login` (chặn `locked`, cập nhật `lastLoginAt`), tạo access (15m) + refresh (7 ngày).
2. Refresh token lưu **băm** vào `refreshTokens`; cookie httpOnly `Secure/SameSite` đọc từ config; `refresh` **rotate** (thu hồi cái cũ, cấp cái mới); `logout` thu hồi.
3. Validator joi, controller, route `/auth/register|login|refresh|logout`; áp limiter nghiêm cho nhóm này.

## Ghi chú cho task sau
- Các endpoint đã sẵn sàng dưới `/api/v1/auth`: `POST /register`, `POST /login`, `POST /refresh`, `POST /logout`.
- Refresh token được băm SHA-256 lưu trong bảng `refreshTokens`, xoay vòng mỗi lần refresh với `jti: crypto.randomUUID()`.
- Cookie `refreshToken` thiết lập `httpOnly: true`, đọc cờ `secure` và `sameSite` từ `app/config/index.js`.
- Độc giả đăng ký được tự động cấp mã `DG...` qua `code.util.js (nextCode('user'))`.
