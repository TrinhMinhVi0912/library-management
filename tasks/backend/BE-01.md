# BE-01 – Khởi tạo project backend
- Track: Backend · Giai đoạn: B0 Khởi tạo
- Phụ thuộc: không
- Phạm vi: **một cuộc trò chuyện**; chỉ làm đúng việc dưới đây.

## Đọc (chỉ những mục này)
- digest §D9
- docs/04 §1.1 (cây thư mục)

## Làm
1. Tạo thư mục `library-backend/` từ cấu trúc mẫu contactbook (hoặc `npm init`) giữ `app/`, `app.js`, `server.js`, `.eslintrc.js`, `.gitignore`.
2. Cài: express mongoose jsonwebtoken bcryptjs joi socket.io cloudinary multer cors helmet express-rate-limit express-mongo-sanitize morgan node-cron dotenv nodemailer cookie-parser slugify sanitize-html exceljs swagger-ui-express; dev: nodemon eslint jest supertest @faker-js/faker.
3. Tạo các thư mục rỗng theo docs/04 §1.1 (`models, middlewares, validators, sockets, jobs, scripts`, thêm các `utils` cần có).
4. Thêm scripts vào `package.json`: `dev`, `start`, `seed`, `create-admin`, `lint`, `test`.
5. Tạo `.env.example` với đủ biến ở digest §D9; `.gitignore` có `.env`, `node_modules`.

## File tạo/sửa

- Dự án backend đã khởi tạo đầy đủ thư mục theo docs/04 §1.1, cài đặt đủ dependencies/devDependencies.

- `app/api-error.js`, `app.js`, `server.js` khung khởi tạo đã sẵn sàng cho BE-02 (Cấu hình, kết nối DB, khung Express, /health).
