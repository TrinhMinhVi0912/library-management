# BE-02 – Cấu hình, kết nối DB, khung Express, /health
- Track: Backend · Giai đoạn: B0 Khởi tạo
- Phụ thuộc: BE-01
- Phạm vi: **một cuộc trò chuyện**; chỉ làm đúng việc dưới đây.

## Đọc (chỉ những mục này)
- digest §D9, D1
- docs/05 §5 (proxy, CORS, cookie)

## Làm
1. `app/config/index.js`: đọc toàn bộ env, đặt mặc định hợp lý, tách danh sách `CLIENT_URL` bằng dấu phẩy.
2. `app/utils/mongodb.util.js`: `mongoose.connect(config.mongodbUri)` + log kết nối.
3. `app/api-error.js`, `app/middlewares/errorHandler.js` (404 + lỗi chung), `asyncHandler`, helper `ok(res,data,meta)`.
4. `app.js`: `trust proxy`, helmet, cors (origin theo config, credentials), json, cookie-parser, mongo-sanitize, morgan, rate-limit chung, `GET /health`, mount `/api/v1` (router rỗng), 404 + errorHandler.
5. `server.js`: tạo `http.createServer(app)`, kết nối DB rồi listen `0.0.0.0:PORT` (chừa chỗ gắn Socket.IO và cron).

## Ghi chú cho task sau
- Helper chuẩn hóa phản hồi: `ok(res, data, meta, statusCode = 200)` và `asyncHandler` trong `app/middlewares/errorHandler.js`.
- Lỗi tập trung: `ApiError` trong `app/api-error.js`.
- Tiện ích DB: `MongoDB.connect(uri)` và `MongoDB.disconnect()` trong `app/utils/mongodb.util.js`.
- Tiền tố API v1: mount tại `/api/v1` qua `app/routes/index.js`.
- Lưu ý Express 5: `express-mongo-sanitize` dùng in-place sanitize cho `req.body`, `req.params`, `req.query` để tránh TypeError do `req.query` là getter.
