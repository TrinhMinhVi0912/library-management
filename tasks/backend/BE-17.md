# BE-17 – notify.service (DB) và API thông báo của tôi
- Track: Backend · Giai đoạn: B4 Mượn trả
- Phụ thuộc: BE-06, BE-08
- Phạm vi: **một cuộc trò chuyện**; chỉ làm đúng việc dưới đây.

## Đọc (chỉ những mục này)
- digest §D4 (notifications), D7
- docs/02 §4.12–4.13; docs/04 §5.1

## Làm
1. `notify.service.js`: `notifyUser(userId,{type,title,content,link})`, `notifyStaff(...)`, `notifyAudience(...)`; **chỉ lưu DB** ở task này nhưng thiết kế sẵn hàm `emit` (no-op khi chưa có io).
2. Endpoint: `GET /me/notifications?unread=`, `/me/notifications/unread-count`, `PATCH /me/notifications/:id/read`, `/read-all` (hỗ trợ thông báo chung qua `notificationReads`).

## File tạo/sửa
- `app/services/notify.service.js`
- `app/controllers/notification.controller.js`
- `app/routes/notification.route.js`

## Xong khi

- [x] Lint sạch; `/done` đã cập nhật INDEX + SESSION

## Ghi chú cho task sau
- `notify.service.js` export: `setIO(io)`, `emit(room,event,data)`, `notifyUser(userId,opts)`, `notifyStaff(opts)`, `notifyAudience(audience,opts)`, `getNotifications(userId,role,query)`, `getUnreadCount(userId,role)`, `markAsRead(userId,notifId)`, `markAllAsRead(userId,role)`.
- `emit()` hiện no-op vì chưa gọi `setIO()`. BE-18 sẽ gọi `setIO(io)` khi Socket.IO khởi tạo.
- API endpoints mount tại `/me/notifications` trong `me.route.js`. Route file: `notification.route.js`.
- Thông báo chung (audience ≠ 'user') dùng `notificationReads` để theo dõi trạng thái đọc riêng từng user.
