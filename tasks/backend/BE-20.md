- Phạm vi: **một cuộc trò chuyện**; chỉ làm đúng việc dưới đây.

- digest §D6 (approveLoan), D7
- docs/04 §4; docs/02 §6

## Làm
1. `approveLoan(loanId, staffId)` trong `session.withTransaction`: loan phải `pending`; từng sách `findOneAndUpdate({_id,availableCopies:{$gte:1}},{$inc:{availableCopies:-1}},{session})`; thiếu → abort + lỗi nêu tên sách hết; set `approved`, `pickupDeadline=now+pickupHoldDays`, `approvedBy/At`.
2. `rejectLoan(loanId, staffId, reason)` (bắt buộc lý do) → `rejected`.
3. **Sau commit**: thông báo độc giả, emit `loan:updated`, cập nhật `staff:counters`; audit log.
4. Route `GET /admin/loans`, `/admin/loans/:id`, `POST …/approve|reject`.

## Ghi chú cho task sau
- `approveLoan(loanId, staffId, options)` chạy trong `session.withTransaction`. Cập nhật tồn kho sách bằng điều kiện `{ availableCopies: { $gte: 1 } }`. Hết sách trả 422.
- `rejectLoan(loanId, staffId, reason, options)` bắt buộc `reason` (string, min 1 ký tự, max 500 ký tự), thiếu lý do trả 422.
- Sau commit/lưu: phát sự kiện socket `loan:updated`, emit `staff:counters`, thông báo độc giả `notifyUser`, ghi `auditService.log`.
- Admin routes:
  - `GET /api/v1/admin/loans`
  - `GET /api/v1/admin/loans/:id`
  - `POST /api/v1/admin/loans/:id/approve`
  - `POST /api/v1/admin/loans/:id/reject`
- Quyền truy cập các route trên: `staff`, `admin`.
