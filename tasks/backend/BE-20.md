# BE-20 – Duyệt / từ chối yêu cầu mượn (transaction)
- Track: Backend · Giai đoạn: B4 Mượn trả
- Phụ thuộc: BE-19
- Phạm vi: **một cuộc trò chuyện**; chỉ làm đúng việc dưới đây.

## Đọc (chỉ những mục này)
- digest §D6 (approveLoan), D7
- docs/04 §4; docs/02 §6

## Làm
1. `approveLoan(loanId, staffId)` trong `session.withTransaction`: loan phải `pending`; từng sách `findOneAndUpdate({_id,availableCopies:{$gte:1}},{$inc:{availableCopies:-1}},{session})`; thiếu → abort + lỗi nêu tên sách hết; set `approved`, `pickupDeadline=now+pickupHoldDays`, `approvedBy/At`.
2. `rejectLoan(loanId, staffId, reason)` (bắt buộc lý do) → `rejected`.
3. **Sau commit**: thông báo độc giả, emit `loan:updated`, cập nhật `staff:counters`; audit log.
4. Route `GET /admin/loans`, `/admin/loans/:id`, `POST …/approve|reject`.
