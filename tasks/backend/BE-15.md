# BE-15 – Seed dữ liệu danh mục & sách
- Track: Backend · Giai đoạn: B3 Sách
- Phụ thuộc: BE-14
- Phạm vi: **một cuộc trò chuyện**; chỉ làm đúng việc dưới đây.

## Đọc (chỉ những mục này)
- docs/02 §7

## Làm
1. Mở rộng `seed.js`: 8–10 thể loại, 15 tác giả, 5 NXB, 50–100 sách (ảnh bìa dùng URL ảnh mẫu hoặc Cloudinary demo, `availableCopies` hợp lệ).
2. Giữ khả năng chạy lại; in thống kê số bản ghi đã tạo.

## File tạo/sửa
- `scripts/seed.js`

## Xong khi
- [x] `npm run seed` tạo đủ số lượng; `GET /books` trả danh sách có ảnh
- [x] Lint sạch; `/done` đã cập nhật INDEX + SESSION

## Ghi chú cho task sau
- `npm run seed` đã hoàn thiện tạo 10 thể loại, 15 tác giả, 5 NXB, 60 sách (58 active, 2 hidden), có đầy đủ ảnh cover URL, availableCopies <= totalCopies, ratings, borrowCount.
- Script có cơ chế xóa sạch và reset counter (user, publisher, book) để chạy lại an toàn bất kỳ lúc nào mà không bị trùng khóa.
