- API cần có từ backend: BE-18 (đã làm ở track BE)
- Phạm vi: **một cuộc trò chuyện**; chỉ làm đúng việc dưới đây.

## Đọc (chỉ những mục này)
- docs/03 §3.2, §5; digest §D8

## Làm
1. Tạo skeleton app riêng từ Vite/Vue 3: package/scripts/dependencies, `.env.example`, `.gitignore`, alias `@`, `main.js`, `App.vue`, styles/tokens theo docs/03 (cùng hệ token user app), router và app shell. Thêm Chart.js/vue-chartjs nếu chưa có.
2. Tạo login/logout/refresh flow riêng dùng cùng API: auth service/store, access token trong memory, refresh cookie với `withCredentials`, `/me` khôi phục session; không lưu token trong localStorage. Login chỉ nhận staff/admin; reader hiện thông báo/link sang website user.
3. `AdminLayout`, `AdminSidebar` (mục theo role; badge yêu cầu mượn/gia hạn qua `staff:counters` + `/admin/counters`), `AdminTopbar`; tạo socket service/store riêng với refresh/reconnect.
4. `DataTable` (sort/filter/pagination, slot hàng, cuộn ngang mobile), `StatCard`, `ChartCard`, `DateRangePicker`; `admin.service.js`; routes có `roles:['staff','admin']`, settings/audit/management staff chỉ admin.
