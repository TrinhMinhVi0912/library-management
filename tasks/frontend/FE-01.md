## Làm
1. Tạo app `library-frontend-user/` từ cấu trúc mẫu contactbook (Vite + Vue 3) giữ `src/{assets,components,router,services,views}`, `App.vue`, `main.js`, `jsconfig.json`, `vite.config.js`. Đây là app user; app quản trị sẽ tạo riêng ở FE-19.
2. Cài các gói dùng cho user app: vue-router pinia axios socket.io-client bootstrap @popperjs/core bootstrap-icons sass vee-validate yup vue-toastification dayjs sweetalert2 (+ eslint). Chart.js/vue-chartjs chỉ cài ở admin app khi cần biểu đồ (FE-19).
3. Tạo thư mục user theo docs/04 §1.2 (`layouts, stores, components/{common,book,loan,forum}, views/{public,reader,forum}`); alias `@`→`src`; `.env.example` (`VITE_API_URL`, `VITE_SOCKET_URL`); `.gitignore` có `.env`.
