# FE-20 – Dashboard quản trị – Kiểm thử giao diện

## Setup
- App admin: `http://localhost:5173/admin` (hoặc origin Vite hiện tại).
- Backend cần chạy và cho phép origin frontend trong `CLIENT_URL`.
- Đăng nhập bằng tài khoản staff/admin có quyền truy cập dashboard.
- Cần có dữ liệu sách, độc giả, phiếu mượn và phạt để đối chiếu số liệu; có thể dùng dữ liệu rỗng để kiểm tra empty state.

## Ghi chú dữ liệu

- API biểu đồ: `GET /api/v1/admin/dashboard/charts?range=7d|30d|12m`.
- API summary: `GET /api/v1/admin/dashboard/summary`.
- Dòng “Sắp đến hạn nhận sách (3 ngày)” được tính từ tối đa 100 phiếu trạng thái `approved` có `pickupDeadline` trong 3 ngày tới; cần đối chiếu trên dữ liệu thực và báo nếu thư viện có hơn 100 phiếu approved đang chờ nhận.
- API Excel: `GET /api/v1/admin/reports/loans.xlsx` với `from` và `to` lấy theo khoảng đang chọn.
