# FE-03 – API/auth/UI stores – Kiểm thử giao diện và kết nối

## Setup
- App/URL: chạy `npm run dev` trong `library-frontend-user/`; ghi lại origin thật mà Vite in ra (ví dụ `http://localhost:5173`).
- Backend/API: đặt `VITE_API_URL` thành URL backend có hậu tố `/api/v1`; `CLIENT_URL` backend phải cho phép origin Vite chính xác. Khởi động lại Vite sau khi đổi `.env`.
- Tài khoản/role và dữ liệu mẫu: để gọi public endpoint không cần tài khoản; auth cần tài khoản reader test. Không ghi credentials/token vào checklist hoặc commit.

## Checklist
| Trạng thái | Luồng | Các bước | Kết quả mong đợi | Kết quả thực tế / ghi chú |
|---|---|---|---|---|
| Chờ test | Public API và CORS | 1. Mở app trên browser. 2. DevTools Console chạy `const { default: api } = await import('/src/services/api.service.js'); await api.get('/books', { params: { page: 1, limit: 1 } });` | Nhận response `{success:true,data,meta?}`; không có lỗi CORS/Network Error. URL gọi đúng `${VITE_API_URL}/books`. | |
| Chờ test | Cấu hình cookie | 1. Trong DevTools Network, kiểm tra request API. | Request gửi credentials (`withCredentials`); không gửi refresh token trong JavaScript/localStorage. | |
| Chờ test | Login và fetch profile | 1. Mở DevTools Console. 2. Import `useAuthStore` từ `/src/stores/auth.store.js` và `pinia` từ `/src/stores/pinia.js`. 3. | Chờ test | Refresh và nhiều request 401 đồng thời | 1. Giữ refresh cookie hợp lệ, làm access token hết hạn. 2. Gửi đồng thời một số request cần auth. | Chỉ một `POST /auth/refresh`; request còn lại chờ, sau đó được gửi lại với access token mới; session vẫn đăng nhập. | |
