# FE-01 – Khởi tạo project frontend – Kiểm thử giao diện

## Setup
- App/URL: chạy `npm run dev` trong `library-frontend-user/`; mặc định Vite.
- Backend/API: không cần backend cho trang khung trống.
- Tài khoản/role và dữ liệu mẫu: không cần đăng nhập hoặc dữ liệu.
