# FE-04 – Component chung (1/2) – Kiểm thử giao diện

## Setup
- App/URL: chạy `npm run dev` trong `library-frontend-user/`, mở `/dev/components`.
- Backend/API: không cần backend.
- Tài khoản/role và dữ liệu mẫu: không cần đăng nhập hoặc dữ liệu.
