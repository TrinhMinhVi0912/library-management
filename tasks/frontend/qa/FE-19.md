# FE-19 – Khởi tạo app admin, auth và layout quản trị – Kiểm thử giao diện

## Setup
- App admin local: `http://localhost:5173` (hoặc origin Vite đang chạy).
- API local mặc định: `http://localhost:5000/api/v1`; backend phải chạy và `CLIENT_URL` phải cho phép đúng origin admin.
- Cần tài khoản `admin`/`staff` và tài khoản `reader` riêng. Không ghi mật khẩu hoặc token vào file này.
- Kiểm tra realtime cần thêm một phiên độc giả và Socket.IO backend đang hoạt động.

## Ghi chú chẩn đoán

- `Network Error` không xác nhận reader bị chặn hay được phép; nó cho biết trình duyệt chưa nhận được HTTP response. Trước tiên xác nhận `/health`, `VITE_API_URL` và CORS `CLIENT_URL`.
- Khi API hoạt động, kiểm tra guard bằng tài khoản reader; không sửa role tài khoản production để thử.
- Realtime cần kiểm tra đồng thời kết nối socket và sự kiện/backend làm thay đổi counter. Nếu badge không đổi, ghi lỗi Console và trạng thái kết nối trong DevTools Network → WS.
