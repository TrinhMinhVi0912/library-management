# FE-38 – Build & deploy frontend
- Ứng dụng đích: Cả `library-frontend-user/` và `library-frontend-admin/`; giữ route/service/build riêng từng app.
- Track: Frontend · Giai đoạn: F5 Hoàn thiện
- Phụ thuộc: FE-37, BE-40
- Phạm vi: **một cuộc trò chuyện**; chỉ làm đúng việc dưới đây.

## Đọc (chỉ những mục này)
- docs/05 §3.2, §6.2, §8

## Làm
1. Hoàn thiện `.env.example`, SPA fallback (`public/_redirects` hoặc `vercel.json`) và README cho cả `library-frontend-user/` lẫn `library-frontend-admin/`; chạy `/deploy-check` cho từng app. Với Vercel monorepo, tạo project riêng, mỗi project chọn root directory tương ứng.
2. Tạo hai static site/build độc lập với cấu hình `VITE_API_URL`/`VITE_SOCKET_URL` riêng; cập nhật cả hai origin trong backend `CLIENT_URL`; kiểm tra SPA fallback, đăng nhập/refresh cookie, Socket và upload trên URL production của từng app.

## File tạo/sửa
- `library-frontend-user/{vercel.json,README.md,.env.example}`
- `library-frontend-admin/{vercel.json,README.md,.env.example}`
