## Làm
1. `api.service.js`: instance `baseURL=VITE_API_URL`, `withCredentials:true`; interceptor request gắn `Authorization` từ auth store; interceptor response: 401 → gọi `/auth/refresh` **một lần** (hàng đợi request chờ), thất bại → đăng xuất + chuyển `/login`; lỗi 4xx/5xx → toast (trừ khi `config.silent`).
2. `stores/auth.store.js` (accessToken trong memory, `user`, `isAuthenticated`, `role`, `login/logout/fetchMe/refresh`), `stores/ui.store.js` (loading, sidebar).

## File tạo/sửa
- `src/services/api.service.js`
- `src/stores/auth.store.js`
- `src/stores/ui.store.js`
- `src/main.js` để cấu hình auth callbacks/toast; `src/router/index.js` để có đích `/login` cho luồng hết phiên.

## Ghi chú cho task sau
- API client: `src/services/api.service.js`, cấu hình callback trong `src/main.js`; request config hỗ trợ `skipAuthToken`, `skipAuthRefresh`, `silent`.
- Auth store: `useAuthStore` ở `src/stores/auth.store.js`; access token nằm trong Pinia memory. `refresh()` dùng refresh cookie và cập nhật user/token; request 401 đồng thời chờ cùng một refresh promise.
- Endpoint kiểm tra CORS đề xuất: `GET /books?limit=1` qua `VITE_API_URL` có hậu tố `/api/v1` (health nằm ngoài prefix API). Backend phải cho phép chính xác origin Vite trong `CLIENT_URL`.
